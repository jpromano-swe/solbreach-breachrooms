# SolBreach Breach Room 1

Scoped Rust/Anchor audit room for practicing agent-assisted Solana review.

## Setup

```bash
npm install
anchor build
```

## Auditor skill

```text
Install: https://github.com/solanabr/auditor-skill
Run from this Rust/Anchor repo: /auditor:audit-cycle
```

## Scope

- `programs/breach_room_1/src/lib.rs`
- `tests/breach_room_1.ts`
- Anchor workspace configuration

## Objective

Find three vulnerability classes in the scoped program and write a concise finding report with root cause, impact, proof, and mitigation.
